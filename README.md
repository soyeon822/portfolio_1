## 📁 폴더 구조

```text
📦 REPOSITORY
 ┣ 📄 index.html    ← 포트폴리오 페이지 (이 파일 하나로 동작)
 ┗ 📄 README.md     ← 지금 보고 계신 문서
```

> 💡 GitHub Pages는 저장소 최상위의 **`index.html`** 을 첫 페이지로 보여줍니다. 파일 이름을 꼭 `index.html`로 맞춰주세요.

## 🚀 GitHub Pages 배포 방법

| 단계 | 할 일 |
| :---: | :--- |
| **1** | GitHub에서 새 저장소를 만듭니다. (예: `portfolio`, **Public**으로 설정) |
| **2** | `index.html`과 `README.md`를 저장소에 업로드합니다. (`Add file` → `Upload files`) |
| **3** | 저장소의 **Settings** → **Pages**로 이동합니다. |
| **4** | **Build and deployment**에서 Source를 **Deploy from a branch**로 선택합니다. |
| **5** | Branch를 `main`, 폴더를 `/ (root)`로 지정하고 **Save**를 누릅니다. |
| **6** | 1~2분 뒤 `https://USERNAME.github.io/REPOSITORY/` 주소로 접속합니다. |

> 🎯 저장소 이름을 `USERNAME.github.io`로 만들면 주소가 `https://USERNAME.github.io/`로 더 짧아집니다.

## ✏️ 내용 수정 가이드

`index.html` 안에서 아래 위치를 찾아 수정하면 됩니다.

| 바꾸고 싶은 것 | 찾을 위치 | 방법 |
| :--- | :--- | :--- |
| 🖼️ 프로필 사진 | `<img src="data:image/jpeg;base64,...` | `assets/profile.jpg`로 저장한 뒤 `src="assets/profile.jpg"`로 교체 |
| 📝 프로젝트 내용 | `<script>` 안의 `const P=[` | 프로젝트별 `meta`, `t`(WHY/HOW/RESULT/INSIGHT) 문구를 수정 |
| 🎨 프로젝트 색상 | `const P` 안의 `c`, `cf`, `ca` | 배경색, 글자색, 강조색을 각각 변경 |
| 🌈 전체 색상 | `<style>` 맨 위 `:root{ ... }` | `--lime`, `--navy` 등 색상 변수를 변경 |
| 📧 이메일 | `href="mailto:..."` | 원하는 주소로 교체 |
| 🔗 새 프로젝트 추가 | `const P` 배열 | 기존 항목을 복사해 내용만 바꾸고 `,`로 이어 붙이기 |
